# Integrations

The MVP includes placeholder cards and encrypted credential storage. Future integrations should add OAuth handlers, token refresh, scoped tool definitions, and audit logs.

Shopify: add OAuth app install, store tokens encrypted, then enable order and product tools.

WooCommerce: store API keys encrypted per organization.

HubSpot: add OAuth scopes for contacts and deals. Deal creation or stage changes require approval.

Calendly: add OAuth and availability lookup. Appointment confirmation requires approval.

Gmail and Slack: outbound messages require approval.

WhatsApp Cloud API: use only for business workflows such as support, lead qualification, appointment reminders, and order tracking. Do not market it as a general-purpose AI assistant.
