# API Keys

OpenAI requires `OPENAI_API_KEY`, `OPENAI_MODEL`, `OPENAI_EMBEDDING_MODEL`, and `OPENAI_MODERATION_MODEL`.

Stripe requires `STRIPE_SECRET_KEY`, `NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY`, `STRIPE_WEBHOOK_SECRET`, and price IDs for paid plans.

SMTP requires host, port, username, password, and from address.

Optional integration client IDs and secrets are placeholders for future OAuth flows and must remain server-side.
